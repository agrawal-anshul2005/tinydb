# Stage Map — Six Fixed SDLC Stages

| # | Stage | Responsible Agent & Model | Inputs & Tools | Saved Artifact(s) | Gate Check Before Moving On | On Failure / Routing |
|---|---|---|---|---|---|---|
| **—** | **Orchestrator** | `orchestrator.py` (**Deterministic Python — No LLM**) | CLI args, env caps, stage exit codes | Run control & `usage.json` aggregation | Enforces every stage gate strictly before proceeding | Halts immediately on failed gate or budget exhaustion. |
| **1** | **Requirements** | `RequirementsAgent` (Gemini `gemini-3.5-flash-lite`) | Sanitized issue JSON (`gh issue view`), `workflow/prompts/skill.md` | `spec.md` | All acceptance criteria (`AC-*`) are concrete, traceable, and objectively testable (`Gate Status: PASS`) | Explain blocking ambiguities in `spec.md`, upload artifact, comment summary on issue, and **stop run**. |
| **2** | **Design** | `ExplorerDesignAgent` (Gemini `gemini-3.5-flash-lite`) | `spec.md`, `ARCHITECTURE.md`, `tools.py` (`list_dir`, `ast` `repo_map`, `read_file_lines`, `search_symbol`) | `design.md` (+ `context.json`) | Deterministic verifier confirms `design.md` names concrete target file paths (`tinydb/` or `tests/`) and function/class symbols (verified against `ast` map or marked new) | Explain gap in `design.md`, upload artifact, and **stop run**. |
| **3** | **Implementation** | `ReproAgent` (PBT-first TDD) + `CoderAgent` (Gemini `gemini-3.5-flash` ×2 → escalates to `gemini-3.7-flash` ×1; fallback `3.6-flash`/`gemma-4-31b-it`) | `spec.md`, `design.md`, `context.json`, `tools.py`, `hypothesis` (dev-only), `SEARCH/REPLACE` patcher on branch `autose/issue-<N>` | `diff.patch` (+ `status.md` baseline) | Patch applies cleanly, `python -m compileall -q tinydb` passes, and `python -c "import tinydb"` succeeds | Retry patch generation within Stage 3/4 retry budget; if still broken, record error in `diff.patch` / log and **stop run**. |
| **4** | **Testing** | `Evaluator` (`pytest` + `hypothesis` PBT) + feedback loop to `CoderAgent` | **Primary:** Hypothesis `@given` PBT invariants (`max_examples=50`, `derandomize=True`); **Secondary:** example boundary tests; **Baseline:** full TinyDB `pytest` suite (`status.md`) | `test_report.md` | New PBT invariants + example AC tests pass AND zero regressions against baseline `pytest` suite | Feed failing `pytest` / shrunk Hypothesis counterexample `stderr` back to Stage 3 Coder (max 2 `gemini-3.5-flash` tries + 1 escalated `gemini-3.7-flash` try). If retries exhaust, explain in `test_report.md` and **stop run** (escalate to human). |
| **5** | **Release** | `DeliveryAgent` (GitHub Models `openai/gpt-4o-mini` + `git` / `gh`) | Branch `autose/issue-<N>`, `spec.md`, `design.md`, `test_report.md` | `pr.md` + PR link | Branch pushed, PR is open (`gh pr view`), and `ci.yml` passes (`gh pr checks`) | Record failure in `pr.md`, upload artifact, and **stop run**. **Never auto-merges.** |
| **6** | **Review** *(Separate GH Actions Job)* | `ReviewerAgent` (GitHub Models `openai/gpt-4o`, fallback `meta/llama-3.3-70b-instruct`; **read-only job**) | Fresh checkout of PR HEAD; **ONLY** Issue text + `gh pr diff` + repo (may run `pytest` read-only). Zero access to Stage 1–5 reasoning | `review.md` | Reviewer posts `APPROVE`, OR **2 review rounds** have been used up | If `FIX_CODE` and round `< 2`: route feedback to **Stage 3**. If `FIX_DESIGN` and round `< 2`: route feedback to **Stage 2**. After round 2 or on `APPROVE`, stop for **Human merge/close decision**. |
