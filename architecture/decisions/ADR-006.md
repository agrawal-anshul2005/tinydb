# ADR 006: Multi-Provider Free-Tier Model Allocation (Gemini 3.x + GitHub Models via `GH_MODELS_TOKEN`) (D6)

## Status
Accepted (v4 — supersedes [archive/ADR-006_v3.md](./archive/ADR-006_v3.md), [archive/ADR-006_v2.md](./archive/ADR-006_v2.md), and [archive/ADR-006_v1.md](./archive/ADR-006_v1.md))

## Context
Our agentic SDLC workflow runs across six stages and bounded retry loops for five evaluation issues under a strict zero-cost constraint. On Google AI Studio's Free Tier (automatic \$0 spending cap), live endpoint probing ruled out `gemini-4-*` (`429`) and `gemini-3.8-flash` (`503`), verifying `gemini-3.5-flash-lite`, `gemini-3.5-flash`, `gemini-3.6-flash`, `gemini-3.7-flash`, and `gemma-4-31b-it`. Subsequently, our first live Actions run on Issue #1 (`44881708823`) demonstrated that Stages 1–4 succeeded on Attempt 1, but calling `models.github.ai/inference/chat/completions` with the default `GITHUB_TOKEN` on our forked repository returned empty responses (`Expecting value: line 1 column 1`).

## Decision
We will retain the empirically verified multi-provider free-tier allocation and zero-LLM deterministic orchestrator from v3, while upgrading GitHub Models authentication and HTTP headers:

1. **Orchestrator (`orchestrator.py`):** **Deterministic Python (no LLM).**
2. **Stages 1–2 (`RequirementsAgent`, `ExplorerDesignAgent`):** **`gemini-3.5-flash-lite`** (fallback: `gemini-3.5-flash` → `gemma-4-31b-it`) via `GEMINI_API_KEY`.
3. **Stage 3/4 Primary (`ReproAgent`, `CoderAgent` attempts 1–2):** **`gemini-3.5-flash`** (fallback: `gemini-3.5-flash-lite` → `gemma-4-31b-it`).
4. **Stage 3/4 Escalation (`CoderAgent` attempt 3):** **`gemini-3.7-flash`** (fallback: `gemini-3.6-flash` → `gemma-4-31b-it`).
5. **Stage 5 (`DeliveryAgent`) & Stage 6 (`ReviewerAgent`):** **GitHub Models** (`openai/gpt-4o-mini` for Stage 5; `openai/gpt-4o` fallback `meta/llama-3.3-70b-instruct` for Stage 6) authenticated via a dedicated fine-grained PAT stored strictly in GitHub Repository Secrets as **`GH_MODELS_TOKEN`** (never hardcoded in code or logs), with explicit `X-GitHub-Api-Version: 2022-11-28` and `User-Agent` headers.

We rejected continuing to rely solely on default `GITHUB_TOKEN` on a forked repository after Run 1 proved it failed silently against `models.github.ai`.

## Consequences
Positive consequences include reliable cross-provider inference on a forked repository, zero Gemini quota spent on Stages 5–6, true cross-provider reviewer independence (Gemini builds, OpenAI/Meta reviews), and zero secrets in code or git history.

Negative consequences include managing a second repository secret (`GH_MODELS_TOKEN`, rotated after grading) alongside `GEMINI_API_KEY`.

Neutral consequences include retaining full per-call logging of provider, model ID, fallback status, and token counts in `usage.json` / `review_usage.json`.
