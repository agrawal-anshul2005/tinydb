# ADR 006 (v4): Multi-Provider Free-Tier Model Allocation (Gemini 3.x + GitHub Models via `GH_MODELS_TOKEN`) (D6)

## Status
Superseded by active [ADR-006.md](../ADR-006.md) (v5) — superseded after Run 4 on Issue #1 (CI `44888636577`) proved that even with a dedicated fine-grained PAT (`GH_MODELS_TOKEN`) and `X-GitHub-Api-Version` headers, `models.github.ai/inference/chat/completions` returned non-JSON HTML (`Expecting value: line 1 column 1`) because the standalone **GitHub Models** service was retired; v5 pivots Stages 5 and 6 to Google AI Studio's separate open-weight **Gemma 4** family (`gemma-4-31b-it` / `gemma-4-26b-a4b-it`), preserving cross-architecture reviewer diversity and high free-tier RPD headroom.

## Context
After Run 1 (`44881708823`) failed against `models.github.ai` using default `GITHUB_TOKEN`, we hypothesized that a forked repository required a dedicated PAT (`GH_MODELS_TOKEN`).

## Decision
We kept Gemini 3.x for Stages 1–4 and switched Stages 5–6 to call `models.github.ai/inference/chat/completions` using `GH_MODELS_TOKEN` plus `X-GitHub-Api-Version: 2022-11-28`.

## Consequences
Stages 1–5 passed and real CI (`44888636577`) succeeded, but both Stage 5 and Stage 6 calls to `models.github.ai` still failed with `Expecting value: line 1 column 1` because GitHub Models had been retired — directly motivating v5's migration to open-weight Gemma 4 (`gemma-4-31b-it`).
