# ADR 007 (v3): PBT-First Hybrid Deterministic and Structured Gate Checks Across All Six Stages (D7)

## Status
Superseded by active [ADR-007.md](../ADR-007.md) (v4) — superseded after Run 2 on Issue #1 (`44884332705`) revealed that `ReproAgent` generated a syntactically valid test file (`py_compile` passed) containing an invalid Hypothesis API call (`st.recursive(..., max_depth=...)`), causing `pytest` collection error (`rc=2`) that poisoned all 3 Coder attempts; v4 adds a deterministic `pytest --collect-only` gate + 1 self-repair pass inside `ReproAgent`.

## Context
Stages 1–6 require deterministic checks wherever ground truth exists, PBT-first testing via `hypothesis` in Stage 3/4, and `--event workflow_dispatch` filtering in Stage 5.

## Decision
We enforced schema/testability checks in Stage 1, AST file/symbol checks in Stage 2, `py_compile` on generated tests + `compileall`/import checks in Stage 3, Hypothesis PBT + full regression in Stage 4, `--event workflow_dispatch` CI polling in Stage 5, and bounded round/verdict checks in Stage 6.

## Consequences
Run `44884332705` proved that `py_compile` alone cannot catch runtime test-collection errors (such as hallucinated Hypothesis keyword arguments); v4 adds `pytest --collect-only` validation directly to Stage 3A (`ReproAgent`).
