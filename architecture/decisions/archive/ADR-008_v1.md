# ADR 008 (v1): Job-Isolated, Fresh-Context, Adversarial Reviewer Independence (D8)

## Status
Superseded by active [ADR-008.md](../ADR-008.md) (v2) — superseded when Stage 6 (`ReviewerAgent`) moved from `gemini-2.5-pro` to **GitHub Models (`openai/gpt-4o` / `meta/llama-3.3-70b-instruct`)**, upgrading from intra-family model diversity to true **cross-provider** independence while saving Gemini free-tier quota.

## Context
An automated code reviewer that shares conversation history, prompts, or write credentials with the implementer suffers from confirmation bias and violates the assignment requirement that the reviewer see only the issue, PR diff, and repository at PR HEAD with no push permissions.

## Decision
We will isolate Stage 6 (`ReviewerAgent`) across four layers: (1) a separate GitHub Actions job (`independent_review`) on a fresh ephemeral runner, (2) read-only code permissions (`contents: read`, `pull-requests: write`, `issues: read` — no `contents: write`), (3) zero access to Stage 1–5 artifacts or reasoning logs, and (4) a distinct adversarial prompt running on `gemini-2.5-pro` (different from `gemini-2.5-flash` used in implementation).

## Consequences
Positive consequences include platform-enforced non-push permissions and clean context isolation.

Negative consequences include remaining within the same Google Gemini model family, relying on deprecated `gemini-2.5-pro`, and spending limited Gemini free-tier RPD quota on PR reviews — all resolved in v2 by moving Stage 6 to GitHub Models (`openai/gpt-4o`).
