# ADR 008 (v2): Job-Isolated, Fresh-Context, Cross-Provider Reviewer Independence (D8)

## Status
Superseded by active [ADR-008.md](../ADR-008.md) (v3) — superseded after Run 4 confirmed GitHub Models (`models.github.ai`) was retired; v3 preserves all four isolation layers while switching Stage 6's distinct reviewer model to open-weight **Gemma 4 (`gemma-4-31b-it` / `gemma-4-26b-a4b-it`)** reviewing proprietary **Gemini 3.5 Flash** code.

## Context
We isolated Stage 6 across runner, permission (`contents: read`), context (no Stage 1–5 artifacts), and provider layers using GitHub Models (`openai/gpt-4o`).

## Decision
We ran Stage 6 in an isolated GitHub Actions job using GitHub Models (`openai/gpt-4o` / `meta/llama-3.3-70b-instruct`).

## Consequences
Runner, permission, and context isolation worked cleanly, but GitHub Models' retirement broke Stage 6 inference in Run 4; v3 retains strict job/permission/context isolation and swaps the reviewer model to open-weight Gemma 4 31B.
